# AI Snippets

مجموعه اسنیپت‌های سفارشی وردپرس و ابزارهای توسعه.

## قرارداد مخزن

- فقط شاخه `main` استفاده می‌شود.
- هر اسنیپت در یک فایل مستقل نگهداری می‌شود.
- نام فایل، نام همان اسنیپت است.
- شماره نسخه و تاریخ آخرین به‌روزرسانی در ابتدای هر فایل درج می‌شود.
- هنگام هر تغییر، همان فایل به‌روزرسانی و نسخه آن افزایش داده می‌شود.
- فایل‌های PHP استاندارد با تگ آغازین `<?php` ذخیره می‌شوند؛ هنگام انتقال به افزونه Code Snippets باید فقط همین خط اول حذف شود.

## اسنیپت‌ها

### ISTT Phonebook

- **فایل:** [istt-phonebook.php](./istt-phonebook.php)
- **نسخه:** 1.0.0
- **شورت‌کد:** `[istt_phonebook]`
- **کارکرد:** دفتر تلفن AJAX برای مطالب دسته `contacts` با جست‌وجو، فیلتر وابسته حوزه و واحد سازمانی، فیلتر تگ‌ها، صفحه‌بندی، سایدبار جزئیات، حفاظت نمایشی ایمیل، QR Code و خروجی vCard.
- **ساختار داده:** عنوان مطلب = نام و نام خانوادگی، چکیده = واحد سازمانی، تصویر شاخص = عکس فرد.
- **فیلدهای ACF:** `istt_contact_zone`، `istt_contact_email`، `istt_contact_external_phone` و `istt_contact_internal_phone`.
- **نحوه استفاده:** فایل را باز کنید، فقط خط نخست `<?php` را هنگام کپی در Code Snippets حذف کنید، Snippet را در حالت Run everywhere فعال کنید و شورت‌کد `[istt_phonebook]` را در صفحه یا قالب آرشیو المنتور قرار دهید.
- **پارامترهای اختیاری:** `[istt_phonebook posts_per_page="30" tags_limit="5"]`.
